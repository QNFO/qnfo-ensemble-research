# PROVENANCE STANDARD (this repository)

1. Every artifact in a cycle is listed in `cycle-N/MANIFEST.json` with its sha256.
2. Writer deliverables are frozen at collection time (hashes recorded; files not modified afterwards).
3. The final Zenodo deposit carries the reconciled paper + ALL interim drafts + artifacts +
   collateral (PUBLICATION SOURCE COMPLETENESS: when in doubt include everything).
4. Zenodo metadata: related_identifiers isSupplementTo -> this repository URL.
5. Provenance of authorship: each writer artifact records writer id, session, model, and timestamp
   in its front matter; the reconciliation report records the reconciling agent.
