## Research idea

Imaginary Boolean value as static element of periodic-sequence Boolean algebra. The author conjectures that the liar-paradox oscillator ι = ⟨U,P,U,P,…⟩ can be promoted from a mere revision-theoretic process to a genuine logical value by constructing a Boolean algebra of eventually periodic truth sequences, with ι as a distinguished element satisfying ι = ¬ι. The central tension: if ι is only a sequence, it adds nothing beyond period-2 revision theory; if it is a value, it must live in a static domain whose operations (negation, conjunction, disjunction) compose coherently. A paper could test this by (1) formally defining the algebra of eventually periodic binary sequences and proving it is a Boolean algebra under pointwise operations, (2) verifying that ι = ¬ι holds as an algebraic identity and that ι is not isomorphic to any classical or three-valued (T,F,N) logic, and (3) simulating the rewriting dynamics (à la Bricken) to show finite-depth unfoldings converge to ι's equivalence class, demonstrating the value is well-defined and computationally approximable.
