## Research idea

Thermodynamic Feedback Limit on Quantum Error Correction Scalability. Claim: software-based quantum error correction is self-defeating because correction overhead (control electronics, wiring, cryo heat load) generates heat that increases physical error rates, creating a positive feedback loop—an 'error correction chasm'—that makes fault-tolerant quantum computing via error-correcting codes physically unrealizable above ~20 K. A paper could formalize this by coupling a surface-code threshold model to a thermodynamic budget: derive error rate as a function of heat dissipated per correction cycle (wiring heat, Kapitza resistance), show whether the feedback loop diverges (no fixed point) for realistic architectures, and compute the maximum code distance / qubit count before the loop destabilizes. Monte Carlo simulation of coupled error-thermal dynamics could test whether a stability threshold exists and whether topologically protected hardware (e.g., chiral anyon braids) escapes it by reducing per-cycle dissipation.
